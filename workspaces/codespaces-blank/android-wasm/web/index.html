2. Add Android-x86 ISO

Choose android-x86_64-9.0-r2.iso. Saving uses the browser File API and Origin Private File System (OPFS), with chunked writes. The ISO stays on this device and is not sent through HTTP.

3. Virtual hard disk

A blank 8 GiB raw hard disk is created in this browser's OPFS after checking the reported storage quota. It is separate from the Android ISO and remains in browser storage across refreshes. Resetting it permanently deletes its contents.

4. Start Android

QEMU-WASM runs in a dedicated browser worker. The Android ISO is attached read-only and the 8 GiB OPFS disk is attached writable; native Codespace QEMU is not used for these files.

Starting from the ISO boots the installer/live system. Install Android to the virtual disk before using the disk-first option.

Architecture status

The browser worker opens OPFS directly. It exposes the ISO through a chunked, read-only Emscripten file node and the raw disk through random-access OPFS synchronous reads/writes; QEMU sees ordinary paths and attaches them to the PC machine's IDE controller.
